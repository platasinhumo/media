# Plata Sin Humo · operación y videos

Medio de finanzas personales en español. Este repo tiene todo lo que usa la sesión automática: empieza por `ops/OPERACION.md`.

- `ops/` manual, estado, experimentos, métricas, temas y decisiones
- `kit/` generador de slides (`psh_render.py`), de video (`make_video_v3.py`), fuente Archivo y spec de ejemplo
- `produccion/` spec y cálculo de cada día
- `v/` videos publicados por Buffer (`v/AAAA-MM-DD.mp4`)

Contenido educativo, no es asesoría financiera personalizada.
